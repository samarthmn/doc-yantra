# Fixture provenance

Fixture records support reproducible internal regression and fidelity checks.
There is no public source export or fixture publication process.

For owner-supplied Word goldens, record the document origin, usage rights,
exact Word/platform/version, source and PDF SHA-256 hashes, reviewer, and
review date in the case ledger. Use synthetic or rights-cleared documents.
Fidelity thresholds are not lowered while an input is awaiting review.
