# Support

Use repository discussions or issues for reproducible, non-sensitive questions
about building and consuming DocYantra. Include the package name and version,
runtime, input format, and a minimal synthetic example. Remove personal data,
secrets, and customer files.

DocYantra is licensed under AGPL-3.0-or-later. Fonts are
optional; install the separate font package only when an offline font catalog is
needed. Enterprise licensing is available only through a separate signed
agreement; see [`COMMERCIAL-LICENSING.md`](COMMERCIAL-LICENSING.md).
