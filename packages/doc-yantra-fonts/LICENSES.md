# Font licenses

The wrapper and package metadata are licensed under AGPL-3.0-or-later in the
package's `LICENSE` file. The font binaries below retain
their upstream licenses; this mixed-license package does not relicense them.

The binaries in `fonts/` are unchanged upstream font files. Their applicable
licence texts ship beside them and are named by each entry in
`fonts/manifest.json`:

- `LICENSE-liberation.txt`
- `LICENSE-noto-cjk.txt`
- `LICENSE-noto-emoji.txt`
- `LICENSE-noto-sans-scripts.txt`
